# 🥷 What is Muimex11?

**Muimex11** is a **100% free** Android game optimizer for **Samsung, RedMagic-style gamers and everyone else**.
It uses [Shizuku](https://shizuku.rikka.app/) to run real system-level commands (ADB-grade) — boosting your FPS, killing lag spikes, cutting heat and stopping stutters **without root**.

> 💗 Project values: **no ads, no paywalls, no premium features — everything free, forever.**

# 📥 Install

1. **Download the APK** from [**Releases → Latest**](https://github.com/Inkflow-Gab/Muimex11/releases/latest) (asset: `Muimex11-x.y.apk`). Builds are signed ✅ — every release is signed by the repo's official key on GitHub Actions.
2. Install it (allow "install unknown apps" if asked).
3. Install [**Shizuku**](https://github.com/RikkaApps/Shizuku/releases) and start it, in one of these ways:
   - **Wi-Fi/Developer options:** enable *Wireless debugging* → in Shizuku pick *Pair via Wireless debugging* → then *Start via Wireless debugging*; **or**
   - **Root:** start directly (no root otherwise needed by Muimex11); **or**
   - **USB with a PC:** `adb shell sh /sdcard/Android/data/moe.shizuku.manager/start.sh` *(one time)*
4. Open Muimex11 → grant Shizuku permission → boost away 🚀
5. Optional: allow **Display over other apps** to use the Game Space dock and monitor.

> ℹ️ Muimex11 and any old Benimaru build are separate apps — you can keep one or both.

# 🛠 Build it yourself / CI

Every push to `main` runs **GitHub Actions → Build Muimex11** and produces a signed `app-release.apk` artifact.
Signing material (keystore, password, alias) lives in **write-only Actions secrets** (`MUIMEX_KEYSTORE_BASE64`, `MUIMEX_KEYSTORE_PASSWORD`, `MUIMEX_KEY_ALIAS`) and is never committed.

**Publishing a new version for everyone via in-app update:**
1. Bump `versionCode` / `versionName` in `app/build.gradle.kts`.
2. Commit → `git tag v<name>`
3. `git push origin main --tags` → CI builds, signs, creates the Release and refreshes `version.json` + `signature.txt` automatically. Installed apps then get the update prompt 🎉

# 🇧🇷 Resumo em Português (BR)

O **Muimex11** é um otimizador de jogos Android **100% gratuito** — sem anúncios, sem premium — baseado no [Shizuku](https://shizuku.rikka.app/) (sem root).

- 🎮 **Game Space flutuante**: bolha arrastável que abre sobre qualquer jogo com **nome + ícone do app aberto** e **contador de FPS ao vivo** (verde/amarelo/vermelho), além de 10 ações: boost de RAM, Game Boost (modo performance no app da frente), performance fixa, bypass térmico, trava 120Hz, modo foco, sem blurs, ciclo de resolução (100/75/50%), monitor e fechar jogo.
- 📱 **Painel Samsung**: Max Boost em 1 toque, desativar GOS (com restauração), RAM Plus off, congelar daemons de log/Device Security/bloat da Samsung, e restaurar tudo.
- 🖥️ **Monitor de hardware flutuante**: temperatura/frequência do CPU, RAM, bateria e internet em tempo real.
- ⚡ Bots de desempenho: RAM Booster, limpeza de cache, freezer de apps, fstrim, modos de performance, refresco de tela até 240Hz, resolução custom + DPI.
- 🎯 Ferramentas de jogo: auto clicker, mira custom, gyro fix, DND de jogo, boost de toque, DNS p/ reduzir ping.
- 📦 Instalador de APK/OBB, terminal Shizuku, status do Shizuku, informações do aparelho.
- 🌎 App em **PT-BR e inglês** com atualização automática pela Steam… ops, pelo GitHub Releases mesmo 😄

**Instalar:** baixe o APK em [Releases](https://github.com/Inkflow-Gab/Muimex11/releases/latest), instale o Shizuku e comece por ele, depois abra o Muimex11 e autorize.
